# ESP32Sx01 - ESP32-S3 MLAB module

![Module Photo](doc/img/ESP32Sx01_top.jpg)

## Description

ESP32Sx01 is a compact MLAB development module based on the ESP32-S3-MINI-1 microcontroller module from Espressif. The module provides a complete development platform for IoT applications with WiFi and Bluetooth connectivity.

## Key Features

* **Microcontroller**: ESP32-S3-MINI-1
  * Dual-core Xtensa® 32-bit LX7 microprocessor
  * WiFi 802.11 b/g/n (2.4 GHz)
  * Bluetooth® 5 (LE)
  * Up to 8 MB Flash
  * Optional 2 MB PSRAM
* **USB Connectivity**: 2x USB Type-C connectors
  * USB programming and debugging
  * ESD protection (USBLC6-2SC6)
* **Power Supply**:
  * Onboard 3.3V regulator (NCP1117-3.3)
  * Input voltage: +5V via USB or external connector
  * Output: +3.3V for ESP32-S3 and peripherals
* **User Interface**:
  * Reset button
  * Boot button for programming mode
  * Power LED (Green)
  * User LED (Red)
* **Expansion**: 
  * MLAB standard connectors
  * Multiple pin headers for GPIO access
  * Crystal oscillator for precise timing
* **Protection**:
  * USB ESD protection

## Applications

* IoT sensor nodes
* WiFi/Bluetooth gateways
* Home automation controllers
* Wireless data logging
* Educational projects
* Rapid prototyping

The module provides access to ESP32-S3 GPIO pins through standard MLAB connectors and pin headers. Refer to the schematic for detailed pinout information.
